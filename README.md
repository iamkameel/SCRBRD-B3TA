# SCRBRD - AI-Powered Cricket Management Platform

Welcome to SCRBRD, a comprehensive, AI-powered cricket management platform built with Next.js, React, ShadCN UI, Tailwind CSS, and Google's Genkit. It provides a full suite of tools for league administrators, coaches, players, and fans to manage every aspect of a cricket season.

## Key Features

### Core Management
- **Full CRUD Operations**: Manage schools, divisions, seasons, fields, and personnel.
- **Team & Roster Management**: Create teams, assign players, and manage team-specific dashboards.
- **Competition Hub**: Administer leagues, cups, and tournaments with ease.
- **Logistics Control**: Manage vehicles, drivers, and transport assignments for matches.
- **User Profiles**: Allow users to manage their own profile information.

### Scoring & Match Engine
- **Live Scoring**: A detailed, ball-by-ball live scoring interface.
- **AI Scorecard Generation**: Automatically generate realistic T20 scorecards for demonstration or to fill in missing data.
- **Full Match Lifecycle**: From scheduling fixtures and setting lineups to viewing detailed results.

### AI-Powered Analytics
- **Match Summaries & Previews**: Generate journalistic summaries of completed games and analytical previews of upcoming fixtures.
- **Player of the Match Selection**: Let the AI analyze the scorecard to determine the MVP.
- **Scouting Assistant**: Upload a photo of a player to get an AI-powered technical analysis.
- **Performance Forecasting**: Predict a player's likely performance based on form, stats, and match conditions.
- **Natural Language Stats Query**: Ask the AI questions about league statistics in plain English.
- **Highlight Reel Generation**: Automatically create visual and descriptive highlight reels of key match moments.

### Advanced UI & Visualizations
- **Role-Based Dashboards**: Every user gets a dashboard tailored to their specific role and needs.
- **Advanced Match Visuals**: Analyze completed games with interactive Manhattan, Worm, and Wagon Wheel charts.
- **Player Performance Tracker**: A dedicated hub to visualize a player's long-term development, including skill ratings, training logs, and performance over time.
- **Strategic Calendar**: A high-level, filterable calendar for admins to plan fixtures and avoid conflicts.
- **Modern UI/UX**: Built with Next.js, React, ShadCN UI, and Tailwind CSS for a clean, responsive experience.

### Governance & Reference
- **Digital Rule Book**: An easily searchable reference for the laws of cricket.
- **User Role Directory**: Clear definitions of permissions and responsibilities for every role in the system.

This project was built in collaboration with Firebase Studio.
