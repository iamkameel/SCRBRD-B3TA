# **App Name**: SCRBRD-Beta-3

## Core Features:

- Input form: Display a form to enter player statistics from a cricket match, and a button to submit
- Match Summary Generation: Given player statistics for both teams, generate a paragraph summarizing the match. This tool will highlight key moments and performances, in language suitable for newspaper publication.
- Summary display: Display the generated match summary on the results page.
- Download result: Provide the user the ability to download match summary for offline usage.

## Style Guidelines:

- Primary color: A vibrant teal (#20c997) to evoke the freshness of the field.
- Background color: A very light gray (#f0f3f5), to provide a clean canvas.
- Accent color: A warm yellow (#ffc857) for interactive elements to attract attention and create engagement.
- Font: 'Inter' (sans-serif) for body text and headlines. Its modern and neutral look is appropriate to a sports results app.
- Use clean, modern icons to represent different cricketing actions and statistics, with an emphasis on clarity and ease of recognition.
- Employ a clean, card-based layout to present match information and statistics clearly. The layout will adapt fluidly to different screen sizes.
- Incorporate subtle transitions and loading animations to enhance user experience without being distracting. For example, a smooth fade-in effect for match summaries and animated progress bars for loading data.
